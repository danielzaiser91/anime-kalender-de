Synchro melden

So läuft es: Titel öffnen, eine Folge starten, dann unten rechts auf den Knopf klicken. Er liest die Tonspuren, die der Player ohnehin geladen hat — Audiodeskriptionen sortiert er aus, die sind keine Synchronfassung. Gibt es gar keine Folge zum Abspielen, meldet derselbe Knopf „nicht abrufbar“.

Wichtig: Der Knopf liest die Sprachen nur, während eine Folge läuft. Auf der Übersichtsseite stehen sie nirgends — dort weiß auch Netflix selbst nichts davon.

Dasselbe Token wie das Repo-Secret LAUF_TOKEN. Es steht in my_secrets.md. Ohne Token sagt der Knopf beim Klick Bescheid.

Geprüfte Titel zurücksetzen

Die Erweiterung merkt sich, welche Titel schon gemeldet sind, und blendet sie aus der Liste aus. Hier wird dieser Merkzettel geleert — die Meldungen selbst bleiben, sie liegen im Worker. Danach stehen alle Titel wieder in der Liste.
