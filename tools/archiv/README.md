# Archiv: einmalige Mess- und Versuchsskripte

Skripte, die eine Frage einmal beantwortet haben und von keinem Lauf, keiner Prüfung und keiner
Doku mehr aufgerufen werden. Sie bleiben hier, falls dieselbe Frage wiederkommt — laufen aber
gegen den Stand von damals und sind nicht gepflegt. Neue Wegwerfskripte gehören ins Scratchpad
der Sitzung, nicht ins Repo (CLAUDE.md, „Codegestalt").
